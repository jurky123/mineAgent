## 验证方式

所有浏览器测试使用 loopback HTTP、一次性账号 / 数据库与模拟 Paper / Node 连接。截图中的 Minecraft 地址为 `mc.example.test`，演示状态保留显眼提示，不能据此判断正式服务器状态。没有读取生产令牌或调用真实模型。

新增 `scripts/paper-ink-visual.mjs` 在同一个进程中启动 mock 服务、注入静态版本并运行 Chromium，退出时关闭浏览器和 HTTP 服务；不依赖 Windows 的 PowerShell 截图环境。运行方式：

```sh
npm run test:paper-ink
# 或指定持久化截图目录
node scripts/paper-ink-visual.mjs /absolute/artifact/path --check
```

基础矩阵为 16 个路由 / 状态 × 4 种宽度主题组合（1440 浅、1440 深、390 浅、320 浅），共 64 张；包含首页演示 / 游客、目录、棋类大厅 / 对局 / 将军 / 终局、Agent / 提示词 / 思考面板、Minecraft、账号、历史与 404。基线与阶段 1–8 均各保存一套 64 张截图。最终额外检查 320 / 390 / 768 / 1280 宽度、DOM 钩子、CSS 重复选择器、镜像一致、焦点和减少动态效果。

测试在临时 systemd 单元串行运行，内存上限 950 MiB、high 850 MiB、禁用该单元 swap。完整回归运行约 5 分 29 秒，峰值 851 MiB，没有构建或重启正式服务。
