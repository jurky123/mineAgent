基线 `a10c5bb`。用户要求移除独立导航内的首页，资料与插件/工具打开各自页面，逻辑参考所给的资料空间和插件截图。

## 当前行为

- `/agent/library`：独立标题/分类侧栏/主区；实际目录、搜索、类型筛选、名称/修改时间排序、列表/网格、目录面包屑、下载及图片预览。后端仍为现有管理员工作区，不创建个人云盘或模板库。
- `/agent/tools`：插件与技能、工具两个分类；从当前账号 `/api/options` 展示真实条目和权限状态。技能的“在会话中使用”只填新对话草稿，不自动执行；没有新增外部插件市场、安装或 OAuth 功能。
- 独立图标栏去掉首页。账号菜单的资料空间也跳新页；原 Workspace 弹窗已移除，`workspace.js` 仅保留旧客户端到新路由的兼容跳转。聊天加号仅保留文件/图片上传。
- 新页复用登录、主题、额度和账号界面，不初始化聊天历史或 SSE。独立URL可直达和刷新。手机使用上下文抽屉，切换分类后解除主区 inert；离开有未发送内容的聊天须先确认。

## 权限与数据

所有页面只有读取和导航，不增加后端世界写入、插件安装或文件写入接口。`/api/workspace` 与文件接口仍由服务器检查管理员，普通账号打开资料页显示权限说明，不预先请求工作区；伪造文件URL仍403。文件链接使用现有登录Cookie，不在URL里复制令牌。文件名/描述使用DOM文本构建；加载失败先清空旧列表，提供重试，切换目录时丢弃过期响应；退出登录清空页面私有条目。

新增两个页面路由仍使用共用 Agent 文档壳；用户明确移除的旧 Workspace ID 和导航首页ARIA标签在展示契约中单独退役，其余ID/ARIA继续保留。回滚门户模式时新路由与原Agent入口一致返回根路径。
