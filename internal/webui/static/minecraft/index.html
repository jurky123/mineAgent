第一次加入

安装步骤

整合包用于电脑端 PCL；手机上可先收藏或复制本页，之后在电脑继续。

  1. 01

    下载已发布的整合包

    核对版本、文件大小与 SHA256，保持文件原格式。本站发布信息未就绪时，请先联系管理员确认兼容客户端。

  2. 02

    拖入 PCL，创建独立实例

    将文件拖入 PCL 窗口，确认新的实例名称后等待安装。不覆盖已有实例；拖入显示禁止符号时，先检查 PCL 是否以管理员身份运行。

    查看 PCL 官方图文帮助 ↗
  3. 03

    完成依赖安装与账户登录

    依赖仍需联网下载。请在启动器中完成游戏账户登录；整合包不包含游戏购买资格，本站不接收 Microsoft 密码。

  4. 04

    启动游戏，进入多人游戏

    在独立实例中打开“多人游戏 → 添加服务器”，粘贴本页已确认的服务器地址。服务器维护时仍可完成安装，恢复后再加入。

安装步骤参考 PCL 官方帮助。本项目尚未完成干净 Windows 环境下的 PCL 导入、启动与进服验证，验证完成前不开放本站整合包下载。

已有客户端

更新与备份

更新前先备份存档、截图、按键和个人配置。新版优先导入为独立实例，不要直接覆盖旧目录。

是否必须更新、旧版本能否进服，将随正式发布记录说明。尚未确认的兼容组合不会标成“可用”。

遇到问题

先找到卡住的那一步

文件损坏 / SHA256 不匹配

删除未完成的下载后重新下载，核对完整 SHA256。仍不一致时停止导入并向管理员反馈版本与错误。

依赖下载失败

在 PCL 中查看具体失败的依赖与下载来源，恢复网络后重试；不要随意替换为其他版本的模组。

Java 不兼容 / 模组冲突

对照发布记录中的游戏与加载器版本检查 Java 和模组，先用全新独立实例重试，并保留启动错误信息。

内存不足 / 启动后退出

先关闭其他占用较大的应用，检查启动器的内存分配与错误报告。本站推荐内存尚待实测，不填写猜测数值。

账户登录失败

在启动器的官方账户登录流程中重试，检查账户与网络；不要把密码或令牌发到本站聊天或反馈截图里。

无法连接 / 服务器维护

先确认地址、客户端版本与服务器状态。安装成功不等于已经进服，维护期间请稍后再试或联系管理员。
