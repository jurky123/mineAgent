# QQ 定向提及、附件原件与成员资料

## 行为

- `qq_member_profile`：`user: "self"` 查询本次发言人；省略 user 列出当前群近期成员，可按 query 昵称筛选、offset 翻页，每页最多20人。返回稳定匿名编号、平台提供的昵称、头像链接、群角色和观察时间。每个范围最多128人，24小时过期，最多128个范围；这是近期观察，不是完整群名单。改名和同名不影响授权身份。
- `qq_mention`：接收当前群的成员匿名编号和回复 text，转换为 QQ 提及格式发送。拒绝跨群、任意 OpenID、额外提及标签和 @全体；同一任务相同内容不重复发送，失败不自动重发。成功只表示平台受理，实际提醒取决于 QQ 权限和客户端。
- `qq_fetch_attachment`：按当前任务附件 id 获取平台链接返回的原始字节，不接受任意 URL/路径。返回格式、实际大小、SHA256；QQ 管理员可获得安全的 workspace 相对路径继续处理，普通用户仅任务临时缓存，无共享工作区和代码权限。

## 资源与真实性

自动处理维持单件32MiB、任务64MiB；超过已知自动预算的附件先登记，按需下载单件最多256MiB、任务累计512MiB（含自动下载）。流式落盘并同时计算哈希，限制实际读取字节，失败清理部分文件；沿用公网下载的 DNS/重定向限制。已有原件不重复下载，生成的内部文件名不取用户文件名。

超过4MiB的图片自动生成有界 JPEG 视觉预览，原始文件独立保留；动图预览仅第一帧，不声称看完动画。不支持的图片交由现有受限解析器处理。小图片、自动预算内视频的关键帧处理继续有效。按需下载本身不额外把完整视频注入模型，也不代表已理解全部内容。

“原件”指平台附件 URL 提供的字节，不能保证是 QQ 压缩前文件。视频链接若实际返回图片封面，明确失败并提示以文件形式发送；不把封面冒充视频。过期链接明确失败，不猜刷新接口。

QQ 官方群聊接口未验证可查询完整个人主页。只返回实际消息字段，不猜 QQ 号，不把频道成员接口用于群聊；年龄、签名等未提供内容不可查询。头像只返回平台给出的链接，不额外爬取个人资料。参考：[官方 SDK 数据结构](https://github.com/tencent-connect/qqbot-agent-sdk/blob/main/src/qqbot_agent_sdk/dto.py)、[官方提及格式](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/message_format.md)。

使用隔离临时数据库、本地模拟 QQ API 和附件源，验证跨群隔离、昵称重名、资料缺失、提及文本/重复发送限制；验证源文件逐字节及哈希一致、缓存去重、路径穿越、普通用户权限、任务清理、流式超限、SSRF 和视频封面误识别。另通过真实 Agent 工具循环模拟查询自己资料并定向回复；没有向真实群成员发送测试消息。

执行相关 QQ/Agent/tools/storage/main 的 Go 测试和 vet，以及 QQ 包 race。线上 QQ 提及提醒、真实媒体 CDN 和实际事件是否提供昵称头像，仍需用户真机确认。
