# QQ 会话模型设置

## 入口与生效范围

QQ `/help` 增加 `/settings` 入口（中文 `/设置`），集中展示当前模型和思考强度及设置方法。私聊直接发送；群聊先 @ 机器人。

- `/model` 查询当前选择；`/model list [页码]` 每页20个真实可选ID；使用完整ID选择，不使用随排序变化的数字序号。
- `/model <完整模型ID>` 设置；`/model default` 或 `/model 默认` 恢复站点默认。
- `/effort low|medium|high|default` 沿用已有思考设置；`/status` 也显示当前模型。

设置按当前QQ会话保存，与网页偏好分开。群内沿用既有共享会话语义，成员可修改当前群当前会话，回复明确说明影响范围。新请求在提交时确定模型，已排队或运行的请求保持原模型。自然接话读取同一设置，继续无工具执行。`/new` 重置，`/fork` 继承，`/resume` 恢复；服务重启仍保留。

## 目录与权限

主程序将网页已过滤模型目录的只含ID回调注入QQ；提供商前缀、配置白名单、免费筛选、缺密钥/不可用状态沿用网页规则，不复制密钥或向QQ提供地址/配置文件。目录去重、分页，查询有5秒请求上下文；当前模型/设置查询及恢复默认不请求目录、不进入模型队列。

网页未启用时仅回退到显式配置的默认提供商列表，以及带密钥且未设置仅免费限制的额外提供商显式列表。没有价格元数据时不开放额外提供商的仅免费列表。可选不等于保证提供商当前额度/调用成功，不新增模型自动回退。

`session_models` 为带外键的新增表，随现有启动建表逻辑创建，不改旧历史。模型设置不授予工具、MC身份、管理员或审批权限；网页与其他渠道命令行为保持。旧客户端/数据库无需手动迁移。
